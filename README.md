# raccourcis-ahk

Deux barres de boutons de raccourcis sur les bords de l'écran (gauche et droite), écrites en AutoHotkey v2 pour Windows : captures d'écran vers Claude, copier/coller, zoom, clavier visuel, etc.

## Utilisation
1. Installer AutoHotkey v2.
2. Télécharger `raccourcis.ahk` et double-cliquer dessus.
